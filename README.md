# Demo-I-am-an-archer
## 独立开发 | Unity 2D 射击 Demo | 2026.3-2026.5
- 项目demo见 Releases
- demo演示见 【demo: I am an archer】 https://www.bilibili.com/video/BV1XgLp6ZErs/?share_source=copy_web&vd_source=327cb65ebe1c61b6e9b3d3ff080906d8
## 主要内容: （角色动作系统、玩家输入、AI行为、寻路导航、子弹系统）
- 实现了继承自 MonoBehaviour 的角色类，封装了一系列角色动作，包括：移动、跳跃、闪避、瞄准、蓄力、射击和换弹，并公开了相应的动作开始、结束方法；
- 基于 new Input System 为 Player 的角色操控实现了多平台输入支持；
- 实现了基于状态机的 AI 决策系统，包括：站立、追逐、攻击、换弹与逃离等状态，其中攻击部分通过求解抛物方程获取合适的角度和蓄力程度，并依此完成攻击行为；
- 开发了自定义的导航工具类，提供了导航图烘培和 A* 寻路两个公开方法以及导航图和路径的调试方法，其基于 Tilemap 与自定义导航图实现了 AI 追踪和路径规划；
- 开发了子弹系统，采用对象池管理子弹实例，子弹弹道（位置）由初速度、角度和时间的函数显式赋值，子弹脚本采用基类继承的方案，便于实现不同的子弹逻辑如：是否受重力影响和发射者是否纳入攻击目标范围，另外还实现了蓄力影响射速/伤害、命中反馈、伤害判定等。
